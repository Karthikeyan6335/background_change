# Background Color Change App (Flutter)

## Overview
The Background Color Change App is a simple and interactive Flutter application that allows users to change the background color dynamically with a single tap or button click.  
It demonstrates basic Flutter concepts like state management, widget rebuilding, and random color generation while maintaining a clean and minimal UI.

Live Demo: [https://background-change-e482d.web.app](https://background-change-e482d.web.app)

## Objective
To create a simple Flutter app that changes background colors randomly upon user interaction, showcasing the use of stateful widgets and UI updates in real-time.

## Features
- Changes background color with a button tap.  
- Generates random colors dynamically.  
- Clean and modern user interface.  
- Works seamlessly on web and mobile platforms.  
- Lightweight and fast-loading Flutter app.  

## Technologies Used
- **Framework:** Flutter  
- **Language:** Dart  
- **State Management:** setState  
- **Hosting:** Firebase Web Hosting  
- **Tools:** Android Studio, Visual Studio Code
